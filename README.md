# CNN Vehicle Sound Classification

Aplikasi klasifikasi audio kendaraan menggunakan model CNN Combo.

## Cara menjalankan

1. Install dependencies:
   pip install -r requirements.txt

2. Jalankan aplikasi:
   streamlit run app.py

## Model
Model CNN Combo dengan input audio berbentuk spectrogram 32x32x1.

## Kelas
Bus, Car (C Class - 4K), Crossover, IDMT Car, Jeep,
Minibus, Motorcycle, Pickup, Sports Car, Truck.
